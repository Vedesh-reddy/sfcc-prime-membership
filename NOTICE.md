# Attribution and terms

This repository contains the `plugin_primemenbership` and `bm_primemenbership` cartridges developed by Vedesh Reddy for Salesforce Storefront Reference Architecture (SFRA) storefronts. They are an SFRA extension, not an official Salesforce product, and need a licensed SFRA storefront to run. The SFRA terms are in [licenses/SFRA-TERMS.txt](licenses/SFRA-TERMS.txt).

The storefront cartridge extends SFRA controllers and `checkoutHelpers` with `module.superModule`, `server.prepend` and wrappers, and implements the `dw.order.calculateTax`, `app.template.afterFooter` and Shop API hooks. No SFRA file is changed or copied.
